A sleek, modern, and minimalist Task Management application built using core web technologies, focusing on clean UI (Glassmorphism) and smooth user experience.

## ✨ Features
*   **Modern Design:** Features a trendy Glassmorphism UI with a vibrant gradient background.
*   **Task Management:** Easily add, edit, and delete tasks.
*   **Task Status:** Toggle completion status with a single click (strikethrough effect).
*   **Smart Filtering:** Ability to hide completed tasks and focus only on active ones.
*   **Persistent Storage:** Uses **LocalStorage** to save your tasks locally, so your data persists even after refreshing the page.
*   **Task Counter:** Real-time display of remaining active tasks.
*   **Fully Responsive:** Optimized for all screen sizes, from mobile phones to desktops.

## 🛠 Tech Stack
*   **HTML5:** Structured semantic elements.
*   **CSS3:** Custom styling using Flexbox, Media Queries, and advanced CSS effects.
*   **JavaScript (ES6+):** Organized using **Modules** to ensure clean, maintainable, and scalable code.

## 📂 Project Structure
The project follows a modular architecture for better organization:
*   `index.html`: The main entry point.
*   `style.css`: All visual styles and animations.
*   `scripts/`: Contains the logic modules.

## 🚀 How to Run the Project
1. Clone the repository or download the files.
2. Since the project uses **JavaScript Modules**, you must run it using a local server (like **Live Server** extension in VS Code).
3. Open `index.html` in your browser and start organizing your day!
